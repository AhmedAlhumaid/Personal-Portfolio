# 📸 How to Add Messi Photos

## Quick Setup

### 1. Profile Photo (Hero Section)
Add a Messi profile photo to show in the hero card:

**File name:** `messi-profile.jpg`
**Location:** `/public/messi-profile.jpg`
**Recommended:** Portrait photo of Messi, square crop works best

### 2. Suggested Photos to Use

You can find great Messi photos from:
- **World Cup 2022 celebration** - Lifting the trophy
- **Barcelona jersey** - Classic blue/red kit
- **Argentina jersey** - Light blue and white stripes
- **Inter Miami jersey** - Pink kit

### 3. Image Specifications

- **Format:** JPG, PNG, or WEBP
- **Size:** 400x400px to 1000x1000px (will be displayed at 200x200px)
- **Aspect Ratio:** 1:1 (square) works best for circular frame

### 4. How to Add Images

```bash
# Simply copy your image to the public folder
cp /path/to/your/messi-photo.jpg /home/user/Personal-Portfolio/public/messi-profile.jpg
```

### 5. Testing

After adding the image:
```bash
npm start
```

The image will appear in a circular frame with a golden border in the hero section!

### 6. Placeholder

If no image is found, you'll see a floating 🐐 (GOAT) emoji placeholder - perfect for the greatest of all time!

---

**Note:** The image has a beautiful hover zoom effect and golden Barcelona-themed border! ⚽💙❤️💛
